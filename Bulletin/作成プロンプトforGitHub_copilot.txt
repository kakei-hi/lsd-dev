あなたはUI/UXに強いフロントエンドエンジニアです。
「徳島大学 地域科学研究」の目次一覧ページを、モダンで読みやすいデザインに刷新して新規に作成してください。
目的は、巻号（年）ごとに論文を見つけやすくし、研究者・学生が使いやすい情報設計にすることです。

# 要件
- 1ページ構成のWebページを新規作成（HTML/CSS/JS）
- デザイン：大学・学術機関らしい落ち着いたモダン（余白、タイポグラフィ重視、過度な装飾は避ける）
- レスポンシブ：スマホ/タブレット/PC
- アクセシビリティ：WCAGを意識（コントラスト、フォーカスリング、見出し構造、aria）
- SEO：適切なtitle, meta, 構造化（可能なら）
- 日本語メイン、ヘッダーに「English」切替リンクを配置（リンク先は仮でOK）
- 既存ページにあった情報要素は必ず含める：タイトル、ISSN（オンライン/冊子）、機関リポジトリへのリンク、巻号（年）、カテゴリ（例：査読論文等）、論文タイトル、著者

# UI仕様
- 上部：固定しないヘッダー（ロゴ相当のマーク+サイト名）＋検索バー＋言語切替（JP/EN）
- メイン：巻号（例：第14巻 2024年）を「カード」または「アコーディオン」で表示
- 各巻号内：カテゴリ（例：[査読論文]）ごとに区切り、論文をリスト表示
- 各論文行：タイトル（リンク）/ 著者 / メタ情報（任意：PDF、DOI、掲載区分タグ）
- 右上またはサイドに「年フィルタ」「カテゴリフィルタ」を設置（JSで簡易実装）
- 検索：タイトル/著者を対象にクライアント側検索（JS）

# データ
- ダミーデータで良いが、以下のような構造で複数年分を入れる
  - volume: 14, year: 2024, sections: { 査読論文: [...], 研究ノート: [...] }
  - 論文：title, authors, link, tags, pdf(optional)

# 技術
- 外部ライブラリなし（Vanilla）で実装
- CSSはCSS変数でテーマ管理（色/余白/フォント）
- フォント：システムフォント（日本語）でOK
- 出力は「完成したHTML（1ファイル）」として提示。コピペで動く状態にする。

# 仕上げ
- 配色：白基調 + 落ち着いたアクセント（紺/藍/徳島らしい深緑系など）
- 余白を広めに、見出し階層を明確に
- フッター：運営情報、著作権表記、問い合わせリンク（仮）を入れる
